# Skazka Cards Releases

Public release repository for Skazka Cards.

This repository contains published Android packages and release metadata only.

## Product

Skazka Cards is the lightweight standalone Steam card-farming app for Android. It focuses on Steam Auth/session restore, CM connectivity, card-drop discovery, Auto Flow, queue, watchdog, history, notifications and verified self-updates.

Broader Steam features such as Library, achievements, badges, inventory, wishlist/prices, trades, keys, statistics and game data belong to Skazka Nexus.

## Compatibility

The repository name `steam-card-farmer-releases`, historical APK asset names and the package `com.kroxaboom.steamcardfarmer` remain compatibility identifiers so existing installs and update chains are not broken.

## Contents

- signed APK releases
- version metadata
- SHA-256 checksums
- RU/EN release notes
- installation/update information

Application source code and secrets do not belong in this repository.
Builds, tests, signing and release gates are performed on HOSTKEY before publication.
